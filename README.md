# Webprogrammierung / Lösung / Media Player

Dies ist die **Musterlösung** zur Aufgabe „Media Player" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *JavaScript*.

Ein Media-Player mit Kachel- und Listenansicht für Musiktitel wird objektorientiert um die fehlende Wiedergabesteuerung und UI-Aktualisierung ergänzt.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
